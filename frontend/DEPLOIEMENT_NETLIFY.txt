🚀 COMMENT DÉPLOYER SUR NETLIFY

OPTION 1 : Drag & Drop (PLUS SIMPLE) ⭐

1️⃣  Ouvre un terminal dans ce dossier

2️⃣  Installe les dépendances :
    npm install

3️⃣  Build le projet :
    npm run build

4️⃣  Va sur : https://app.netlify.com/drop

5️⃣  Glisse le dossier "dist" qui vient d'être créé

6️⃣  ✅ TON SITE EST EN LIGNE !

═══════════════════════════════════════════════════════════════

OPTION 2 : Via GitHub

1️⃣  Upload ce dossier "frontend-netlify" sur GitHub
    (renomme-le en "frontend")

2️⃣  Sur Netlify : "New site from Git"

3️⃣  Connecte GitHub

4️⃣  Configuration :
    • Base directory : frontend
    • Build command : npm run build
    • Publish directory : frontend/dist

5️⃣  Environment variables :
    VITE_API_URL = https://calendrier-avant-jtff-production.up.railway.app

6️⃣  Deploy !
